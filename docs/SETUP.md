# Setup

This repository currently has no runtime, dependencies, or build step.

## Local setup

```sh
git clone https://github.com/pcnahar26/cowork.git
cd cowork
```

No additional installation is required for the starter scaffold.

## Picture workflow

- Place original/source pictures in `pictures/input/`.
- Place outputs created during the trial in `pictures/output/`.
- Place optional examples, targets, or other visual references in `pictures/reference/`.
- Use descriptive filenames when practical.
- Do not commit secrets, credentials, or pictures that should not be public; this repository is public.

## Extending setup

If code or tooling is introduced later, document the exact prerequisites and commands here. Add dependency manifests or configuration only when the trial actually requires them.
